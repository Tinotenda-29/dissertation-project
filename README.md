# dissertation-project
This repository presents an end to end machine learning framework designed to assess the impact of COVID 19 on global mental health by leveraging an embedded Latent Dirichlet Allocation (LDA) topic modeling workflow for systematic literature reviews. Built using Python and core text  mining libraries such as Gensim, NLTK and Pandas, the system features a robust preprocessing pipeline that handles deduplication, deep text cleaning, tokenization, lemmatization and customized stop word filtering. To capture nuanced domain specific terminology, the architecture includes automated feature engineering for bigram phrase detection alongside Bag of Words (BoW) vectorization and optional TF IDF optimization. Furthermore, the repository implements systematic hyperparameter tuning to evaluate  coherence scores across varying topic numbers, enabling automated optimal topic selection, comprehensive keyword extraction and clear theme visualization. Ultimately, this tool accelerates health informatics research by turning massive, unstructured text corpora into structured, actionable and datadriven thematic insights.
